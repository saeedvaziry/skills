# Plan Presenter

## MDBIN

Use this path if mdbin mcp was available:

- Use markdown to write the plan
- Combine with mermaid graphs (if needed)
- Use mdbin mcp to create a plan file in markdown
- Share the mdbin link to the user
- Use mdbin mcp and this plan for the implementation itself

## HTML

Use this path if mdbin mcp wasn't available:

- Use short and human understandable sentences
- Combine with mermaid graphs (if needed)
- Show a prototype ui design if it includes ui work (as html)
- Create an html file with all graphs and designs and visual elements and open the file in browser
- Use larger fonts and aligned elements
- Create the html file in tmp dir and open in browser
- Add dark and light mode support to the html adopting the system theme
- IF the plan is multi-phase, add navigation to the html files so user can navigate between each phase's plan
- Use a markdown version of this plan for implementation
