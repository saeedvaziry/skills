# Skills

I am putting all the skills I make or use here

Most of the skills are inspired by https://github.com/mattpocock/skills

## Plan Presenter

This opens the agent plan in a nicely designed HTML page with Graphs for better understanding

```sh
npx skills add https://github.com/saeedvaziry/skills/tree/main/skills/plan-presenter
```

## Design Proposal

A design proposal in HTML before finalizing and proceeding

```sh
npx skills add https://github.com/saeedvaziry/skills/tree/main/skills/design-proposal
```

## Check codex context remaining

This is a skill helping codex cli to know how much of the context window remaining. It can be useful for autonomous workflows to keep the model in the smart zone.

```sh
npx skills add https://github.com/saeedvaziry/skills/tree/main/skills/check-codex-context-remaining
```
